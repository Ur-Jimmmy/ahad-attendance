# Ahad Smartphone Selfie Attendance

Updated UI based on the supplied AHAD SMART PHONE / SELFIE ATTENDANCE design reference.

Features:
- Black/gold branded UI with rounded animated logo treatment.
- Automatic store-location verification on page load.
- Unit 1 and Unit 2 geofence with an 8-meter allowed radius.
- Outside-store random funny/angry message with Google Maps button.
- Selfie camera with centered face guidance circle.
- Manual capture button and retake button.
- Mirror selfie capture.
- Attendance submission remains connected to the existing Google Apps Script URL.
- QR/scan-to-check-in UI removed.
