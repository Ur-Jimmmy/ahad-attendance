Ahad Smartphone Attendance System

Auto Selfie • GPS Location • Google Sheets & Drive Integration

A smart, streamlined attendance solution developed for Ahad Smartphone, designed to make attendance submission faster, more reliable, and user-friendly.

✨ Key Features

- Automatic GPS Location — GPS location tracking begins automatically when the camera is opened.
- Automatic Face Detection — The system attempts to capture a selfie when the face is centered and held steady.
- Manual Selfie Capture — Users can manually capture their selfie using “✨ Lock In My Selfie” whenever needed.
- Current Location Option — A manual “Get Current Location” option remains available.
- Mirrored Selfie — Captured selfies are saved in mirrored format.
- Google Sheets Integration — Attendance records remain connected through the existing Google Apps Script and Google Sheets setup.
- Google Drive Integration — The existing Google Drive connection is preserved for attendance-related data and files.
- HTTPS Support — The website must be accessed through HTTPS because face detection uses MediaPipe Face Detection via jsDelivr.

🔄 Attendance Process

1. Open the attendance website.
2. Grant camera and location permissions.
3. GPS tracking starts automatically.
4. Position your face within the camera frame.
5. Allow the system to automatically detect and capture your selfie.
6. If automatic capture is unsuccessful, use “✨ Lock In My Selfie”.
7. Review the captured information.
8. Submit your attendance.
9. The attendance information is processed through the connected Google Apps Script, Google Sheets, and Google Drive system.
